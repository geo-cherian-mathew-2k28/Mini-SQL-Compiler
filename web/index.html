Transformed Context-Free Grammar ($G'$)

Optimized for Deterministic Recursive-Descent Parsing (Left-Recursion Eliminated & Left-Factored):

<Query>          ::= <SelectClause> <FromClause> <OptWhere> <OptOrderBy> [';']
<SelectClause>   ::= 'SELECT' ( '*' | <ColumnList> )
<ColumnList>     ::= IDENTIFIER ( ',' IDENTIFIER )*
<FromClause>     ::= 'FROM' IDENTIFIER
<WhereClause>    ::= 'WHERE' <OrExpr>
<OrExpr>         ::= <AndExpr> ( 'OR' <AndExpr> )*
<AndExpr>        ::= <ComparisonExpr> ( 'AND' <ComparisonExpr> )*
<ComparisonExpr> ::= '(' <OrExpr> ')' | <Expression> <RelOp> <Expression>
<RelOp>          ::= '=' | '!=' | '<>' | '<' | '<=' | '>' | '>='
<OrderByClause>  ::= 'ORDER' 'BY' <OrderByItem> ( ',' <OrderByItem> )*
<OrderByItem>    ::= IDENTIFIER [ 'ASC' | 'DESC' ]

Operator Precedence Hierarchy

Priority 1 (Highest)Parentheses ( ... )
Priority 2Relational Operators (=, !=, <, >, <=, >=)
Priority 3Conjunction (AND) — Left-Associative
Priority 4 (Lowest)Disjunction (OR) — Left-Associative
